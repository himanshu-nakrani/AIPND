# Portfolio Website Repository

This repository contains a starter portfolio website you can customize and deploy.

## Project structure

```text
.
├── assets/
├── index.html
├── styles.css
└── script.js
```

## Getting started

1. Open `index.html` in your browser.
2. Update the text in the hero, about, projects, and contact sections.
3. Replace placeholders in `assets/` with your own images, resume, or icons.

## Deployment options

- GitHub Pages
- Netlify
- Vercel

## Notes

- The site is fully static and does not require a build step.
- The footer year is set automatically by JavaScript.
